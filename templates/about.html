AttendEase

College Event Attendance Management System

A modern Django-based web application designed to streamline the process of requesting and approving attendance for college events. Built with role-based access control for Students, Coordinators, and Teachers.

Key Features

Role-Based Access

Dedicated dashboards and permissions for Students, Coordinators, and Teachers.

Event Management

Create, edit, and manage college events with full CRUD operations.

Approval Workflow

Multi-level attendance approval from Coordinators to Class Teachers.

Division System

Division-based student grouping with dedicated teacher assignments.
